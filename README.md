# NiNyYoon Blog

Welcome to the source code for [NiNyYoon](https://songwoody.github.io/), a technical blog covering Computer Science fundamentals and software engineering.

## 🚀 Built With

- **[Gatsby](https://www.gatsbyjs.com/)**: A React-based open source framework with performance, scalability and security built-in.
- **[React](https://reactjs.org/)**: A JavaScript library for building user interfaces.
- **[TypeScript](https://www.typescriptlang.org/)**: TypeScript extends JavaScript by adding types.

## 🛠️ Development

1.  **Clone the repository**

    ```shell
    git clone https://github.com/SongWoody/SongWoody.github.io.git
    cd SongWoody.github.io
    ```

2.  **Install dependencies**

    ```shell
    npm install
    ```

3.  **Start the development server**

    ```shell
    npm start
    ```

    The site will be running at `http://localhost:8000`.
